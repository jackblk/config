# Marta

- `Plugins/ghostty.lua`: adds Ghostty to Open With (`Cmd+Enter`) and opens a folder in a new Ghostty tab.
- `Plugins/vscode.lua`: opens a folder in VS Code.
- `conf.marco`: theme, `F11` to open in Ghostty, `Cmd+Shift+Enter` to open in VS Code.

Install with `./install.sh`, then restart Marta.
